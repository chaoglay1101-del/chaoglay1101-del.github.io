Web studio, co-founded

TechStarterWeb: a studio website that is also its order desk

TechStarterWeb Consulting builds personal and small-business websites for clients in Taiwan, Hong Kong and Singapore. I co-founded it in October 2026 and lead the technical side. The studio's own site, live since 23 October 2026, is its first piece of work.

Astro · Cloudflare Workers · Cloudflare D1 · Cloudflare Access · OpenCC

1The need

One site for clients and for the studio

The public pages take enquiries in three languages; a back office behind sign-in turns each one into an order with a status and a log of every change.

2In use

Private by design, and live on its own domain

Only the team's addresses can sign in to the back office, through Cloudflare Access with one-time email codes. The site is live on its own domain, with Google Search Console and visit statistics.

3Limits

What it does not do yet

Enquiries are not yet emailed to the team, and Cloudflare's free plan has no servers in mainland China, so some networks load the site slowly or not at all.

4How it was built

Built with an AI coding agent, in five layers

I set the requirements and review each change; the agent writes the code. Routine work goes to cheaper models: ten calls to the low-cost model came to about US$0.03.

5How it stays on track

Task cards and checks keep every change in bounds

Each task card lists its goal and the files it may change, and CI fails a pull request that breaks the rules.

    Business Analytics coursework

    Mobile money adoption in the Global South

    An individual Tableau story, submitted in December 2025: five dashboards on how mobile money is spreading across the Global South, built from World Bank Global Findex and GSMA data.

    Tableau · Excel · Python · World Bank Findex and GSMA data

    1The data

    From 437 coded fields to 24 measures

    An extract of 437 coded Findex fields across 174 economies was mapped down to 24 business-readable measures. The 2011 and 2022 waves were dropped for thin coverage, leaving 171 economies.

    2The story

    Five dashboards, each with an insight and a recommendation

    A cover opens the story, five interactive dashboards follow, and a conclusion closes it.

    3What it found

    Mobile money leads in Sub-Saharan Africa

    Adoption expanded steadily from 2014. Digital payment use runs ahead of debit-card ownership, and savings trail both.

    4Limits

    What the data cannot show

    My critical assessment of each dashboard names the limits: no transaction-level detail and no qualitative evidence.

    5Where it led

    It led to my final-year research

    Digital payment use running ahead of debit-card ownership raised the question my final-year project tested: what happens to banks' fee income as payments move away from cards.

      Open source

      layered-ai-dev-workflow: how the studio works with AI coding agents

      The layered way of working that TechStarterWeb uses with AI coding agents. The five-layer figure is in the TechStarterWeb project above.

      1The idea

      A lead agent plans, worker agents build, CI checks

      A lead agent turns a to-do into a task card, worker agents write the code, and scripts and CI check whatever a rule can decide.

      2State

      State lives in GitHub, not in chat

      Work state is kept in issues and handoff notes, so a new session can pick up where the last one stopped.

      3Rules

      Rules are enforced by checks

      CI fails a pull request that edits files outside its task card, reuses a version number or skips the spec update.

      4Reuse

      Open source, with tests

      Published with tests, so that others can reuse or adapt it.
